# SKILL: Frontend Layout Refactoring

## Description
Refaktoryzuj i oczyszczaj kod HTML/CSS zgodnie z wyczuciem doświadczonego frontend developera. Pamiętaj o czytelności, poprawności tagów i prostocie, usuwając szum oraz tymczasowe komentarze, przy zachowaniu spójności wizualnej (np. utrzymanie dotychczasowych motywów, p. "ticking bomb").

## Context
Ten skill znajduje zastosowanie, gdy użytkownik ładnie prosi o "refaktoryzację w stylu doświadczonego frontend developera", "uporządkowanie struktury" czy też przygotowanie gotowych fundamentów na przyszłość.

## Instructions
1. Przeanalizuj plik pod kątem błędów składniowych, literówek i wstrzykniętych znaków kontrolnych (np. nieistniejące tagi `8button`, urwane litery itp.).
2. Napraw ewentualne mankamenty kodowania (złe encje, ukryte spacje i litery w aria-labels).
3. Zadbaj o przejrzysty wcięty kod z jednolitymi tagami kontrolowania sekcji (header, main, footer, article, section).
5. Powstrzymaj się od burzenia wizualnego stylingu – aplikacja dalej musi funkcjonować zgodnie z logiką powiązanych plików CSS i JS.
6. Jeśli używasz narzędzia replace i nie dają one skutku z powodu uszkodzonych znaków, nie wahaj się wgrać kompleksowego wariantu pełnego tekstu do pliku w razie mniejszych problemów.
